# Glossary

## For agents

- Lets you: Map a Lyra term to its meaning and page.
- Tools: `docs_search`

| Term | Meaning |
|---|---|
| Lyra | Your personal portfolio manager, the one you talk to |
| Pod | One idea with its own Analyst, Trader, book and forecasts |
| Fund | Your pods in one mode, Paper or Live |
| Analyst | Writes a pod's thesis and dated forecasts |
| Trader | Keeps a pod's book in line with its thesis |
| Trade Agent | The Analyst and Trader shown as one |
| Risk Agent | Reduces or blocks trades; never adds |
| Book | The legs a pod holds, on each venue |
| Leg | One instrument and side in a book |
| Check | A test of a claim on past cases with a sealed final period |
| Past case | One start date and horizon the claim is tested over |
| Hit rate | Past cases that held over all past cases, as "10 of 15 past cases" |
| Awesome Idea | The top grade; needed to run a rule pod |
| Good Idea | Past cases agree; not every test passed |
| Not sure | Past cases do not back it |
| Impossible to verify | Too little history or no way to test |
| Sealed period | The last 365 days, kept out until it opens once per family and period |
| Family | An idea and all its versions |
| Trial | One version checked; it raises the bar for the next |
| CPCV | Combinatorial purged cross-validation: many train and test splits of history |
| PBO | Probability that the best version is overfit |
| Rule | A formula that sets a pod's weights each day |
| Alpha | A rule written in the expression language |
| Research | The tab pair Public Research and Your Research |
| Ideas | Lyra's 3 daily ideas in Public Research, found and tested by Lyra |
| Your Research | Your own views and their research runs |
| Second look | An idea that is a near miss that holds in recent days and in similar instruments |
| Lyra Data Engine | Lyra's engine from raw inputs to point-in-time fields |
| `lde.score` | The engine's news and filings score, -1 to 1 |
| Point in time | A value is used only after it was first public |
| Loss levels | Reduce and close levels, from a pod's peak |
| Reduced | A pod whose capital was cut by 50% at its reduce level |
| Paper | Hyperliquid paper at $10,000 per fund, and your linked Alpaca paper account's equity, read live |
| Live | Your own accounts, real money |
| Ultra workspace | An invite-only workspace with a research agent |
| `ultra.<ns>.*` | Fields only your workspace's rules can read |
| MCP | The protocol your own agent uses to reach Lyra |
| Credits | The unit for chat and research; 1 credit is $0.01 of AI cost |
