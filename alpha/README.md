# Lyra alphas

- [Data sheet](data.md): Every field: meaning, unit, when it is known, coverage.
- [Settings](settings.md): Delay, decay, neutralization, rebalance, truncation, weights, limits.
- [Output](output.md): The standard output of a simulation.
- [Submission checks](checks.md): What alpha_submit requires, the quota and repeated variants.
- [Example alphas](examples.md): Fourteen complete alphas, one pattern each.
- [Claude Code skill](skill/SKILL.md): The validate, simulate, revise, submit loop.
